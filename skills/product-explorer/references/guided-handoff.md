# Guided handoff

A handoff gives the user one small, exact task on a screen the agent has already opened.

## Shape (always the same)
1. **Stage:** navigate to the exact screen and leave it open. Confirm with a screenshot that it is showing.
2. **Ask:** one or two lines: what to tap or type, and why it matters for the research. Name the button by its visible label. If the user should not enter real personal content, say so and suggest test text.
3. **Wait:** for "done" (or a recording, or a file).
4. **Capture:** screenshot and record the result in session notes, structure only.
5. **Continue:** mark the MAP node, move to the next item, and say what is next.

## When to hand off
- Sign-in, passwords, codes, two-factor prompts.
- Typing into fields the tool cannot type into.
- Saving or completing anything that changes real data (for example completing one onboarding flow start to finish).
- Purchases, trials, cancellations (usually: do not do them; read the screens instead).
- Time-bound moments: a scheduled reminder, a notification, an event day. Schedule a reminder if the session tools allow it.
- Exports: the user exports their own data and places the file where the agent can read it.
- Screen recordings: the user records and shares; the agent reads frames.

## Wording examples
- "The project editor is open. Please tap Save on a project named 'Test project' so I can see what happens after saving. You can delete it afterward if you want."
- "Settings > Your Data is open. If you are comfortable, tap Export and save the file to Downloads. I will read field names only, never your entries."
- "When the next scheduled reminder arrives, please open it and record the screen until you are back on Home."
